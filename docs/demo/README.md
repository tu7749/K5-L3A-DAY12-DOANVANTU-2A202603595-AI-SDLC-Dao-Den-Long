# Video demo chờ người dùng quay

Chưa có demo.mp4. Không tạo clip giả từ output test hoặc ảnh chụp.

Kịch bản dưới5phút:
1. Giới thiệu ba Đêm và lựa chọn Chuẩn/Hỗ trợ; chơi trực tiếp một đoạn, nhặt đom đóm, thắp/châm dầu, lướt và pulse.
2. Hiện tùy chọn đổi phím/chữ lớn/màu; cho thấy bảng điểm sau kết thúc.
3. Terminal: npm test; chạy headless scenario Phase3; chạy bench30s và mở bench.json; cho thấy soak.json có10 Đêm/crashes0/RSS.
4. Lướt AGENTS.md, ADR/changelog, các tag phase-1/2/3/4 và Releasev1.0.0.

Quay thật bằng OBS hoặc công cụ hệ điều hành; mp4 dưới5phút. Đính kèm Releasev1.0.0 hoặc đặt docs/demo/demo.mp4 nếu dưới100MB, rồi thêm link đầu README. Tránh quay API key/token hay cửa sổ riêng tư. Mô tả đúng giới hạn: benchmark trên máy phát triển, không phải máy chấm.
